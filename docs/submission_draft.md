# AI 先锋未来人才大赛报名素材草案

## 项目名称

TrialScopeAI——临床试验入排标准结构化与招募可行性评估助手

## 一句话介绍

将临床试验方案中的自然语言入排标准转为可审核规则，在合成患者队列中模拟预筛，帮助药企提前发现招募瓶颈与人群代表性风险。

## 开题报告 Part 1：命题前置分析与洞察（50—300字）

临床试验招募效率不仅取决于患者数量，也受到入排标准复杂度、数据可获得性和人群代表性的共同影响。实践中，方案中的年龄、疾病严重程度、用药史、检查阈值和时间窗通常以长篇自然语言呈现，人工预筛耗时且不同研究中心理解可能不一致。过度严格或难以执行的标准还可能缩小候选人群，引入选择偏倚并降低研究结果的外部可推广性。因此，与其覆盖临床试验全流程，我们聚焦“入排标准结构化与招募可行性评估”这一可量化环节。

## 开题报告 Part 2：整体解决方案设计（300—600字）

TrialScopeAI 面向药企临床开发、医学与运营团队，支持输入 ClinicalTrials.gov 的 NCT 编号、粘贴标准文本或上传可搜索的方案 PDF。系统首先从方案中定位入组与排除章节，再由 DeepSeek 将自然语言转为包含字段、运算符、阈值、单位、时间窗、适用条件、置信度和原文出处的结构化规则；医学人员可逐条审核修改，主观或数据不足的标准自动标记为人工复核。审核后的标准由确定性规则引擎应用到合成患者队列，输出“模拟符合、不符合、信息不足、人工复核”四类结果，并为每名患者保留患者值、阈值、判定原因和标准原文证据。分析端进一步展示招募漏斗、主要排除原因、缺失字段、年龄与性别等代表性差异，并支持对年龄、吸烟包年、肺功能和时间窗进行 What-if 情景模拟。首版以公开 COPD Ⅲ期试验 GOLDEN-4 和500名固定种子的合成患者为案例，不使用真实个人信息。创新点在于“医学语义提取+可解释规则引擎+预防医学代表性分析”的结合，在保证人工审核和安全边界的前提下，为方案可执行性和招募风险提供可量化、可追溯的讨论依据。

## 建议量化目标

- 入排标准结构化提取 F1 目标不低于 0.85；
- 可执行规则患者匹配准确率目标不低于 90%；
- 标准原文和来源追溯率 100%；
- 对缺失和主观标准不做静默排除；
- 使用合成队列展示基线与情景方案的候选人数变化。

以上均为原型验收目标，不表述为已经实现的企业业务增益。

## 演示顺序建议（2—3分钟）

1. 用 20 秒说明招募瓶颈与项目边界；
2. 上传演示 PDF，展示自动定位入排标准；
3. 展示结构化规则、置信度、原文和人工审核；
4. 运行 500 人预筛，点开一个患者的证据链；
5. 展示漏斗和主要排除原因；
6. 调整吸烟包年或肺功能阈值，展示情景变化；
7. 以代表性分析、合成数据和人工审核边界收尾。
