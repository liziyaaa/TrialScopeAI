# AI 先锋未来人才大赛报名素材草案

## 推荐队伍名称

循证智筛

## 所选企业命题

健康元药业

## 项目名称

TrialScopeAI——临床试验方案约束仿真与招募可行性协同决策平台

## 一句话介绍

将临床试验方案转成可审核、可计算的约束，在合成候选人群中比较每项标准对招募规模、数据负担与人群代表性的影响。

## 开题报告 Part 1：命题前置分析与洞察（50—300字）

临床试验招募并非单纯的“患者不足”问题。方案中的年龄、肺功能、合并症、用药史与时间窗常以长篇自然语言呈现，人工逐条解释耗时，不同中心还可能产生执行差异。FDA 2025年指南强调，应审视入排标准对代表性人群参与的影响；相关研究也表明，自然语言处理可降低标准结构化与初筛的人工负担。因此我们聚焦健康元临床开发中可量化、数据可获得的环节：将入排标准转为可审核规则，并在合成队列中提前识别招募瓶颈、数据缺口与代表性风险。

## 开题报告 Part 2：整体解决方案设计（300—600字）

TrialScopeAI 面向健康元临床开发、医学、统计与运营团队，形成“方案导入—标准结构化—协同审核—候选人群仿真—情景权衡”的闭环。用户可输入 NCT 编号、粘贴标准或上传文字型 PDF；系统定位入组/排除章节，通过大模型提取字段、运算符、阈值、单位、时间窗与适用条件，再由医学人员在应用或飞书多维表格中逐条确认。确认后的规则由确定性引擎在固定合成候选人群中执行，每项结果都保留候选者值、规则阈值、判定原因和方案原文。分析端不止统计排除人数：系统会逐项暂不执行可计算标准，反事实测量该约束对候选规模和人群构成的边际影响；情景沙盘则同时呈现候选规模、代表性差异与数据未决负担，供多角色讨论取舍。模型负责理解，规则负责执行，人负责最终审核；系统不自动建议放宽条件，也不替代医学、统计与伦理判断。首版使用 GOLDEN-4 公共方案、27条人工审核规则、500名固定种子合成候选者和50个边界病例，不依赖真实患者数据即可复现演示。

## 建议量化目标

- 入排标准结构化提取 F1 目标不低于 0.85；
- 可执行规则患者匹配准确率目标不低于 90%；
- 标准原文和来源追溯率 100%；
- 对缺失和主观标准不做静默排除；
- 使用合成队列展示基线与情景方案的候选人数变化。

以上均为原型验收目标，不表述为已经实现的企业业务增益。

## 演示顺序建议（2—3分钟）

1. 用 20 秒说明招募瓶颈与项目边界；
2. 上传演示 PDF，展示自动定位入排标准；
3. 展示结构化规则、置信度、原文和人工审核；
4. 运行 500 人方案约束仿真，先展示候选规模和主要瓶颈；
5. 查看单项标准边际影响，说明哪项约束对候选池影响最大；
6. 调整吸烟包年或肺功能阈值，同时比较规模、代表性和数据负担；
7. 点开一个候选者的证据链，以合成数据和人工审核边界收尾。
