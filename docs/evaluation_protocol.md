# 原型评测方案

## 1. 评测对象

- AI 入排标准结构化；
- 确定性患者匹配；
- PDF/NCT 输入可靠性；
- 解释与来源追溯；
- 无网络情况下的演示可用性。

## 2. 数据

- 公开 GOLDEN-4 注册标准；
- 27 条人工审核结构化规则；
- 500 名固定种子的合成候选患者；
- 50 个独立构造的边界病例。

不使用真实患者、医院电子病历或个人信息。

## 3. 指标

### AI 结构化

- 类型、字段、运算符、阈值、单位、时间窗的精确率、召回率和 F1；
- 主观标准识别率；
- 有效 JSON 成功率；
- 原文和来源追溯率。

2026 年 8 月 16 日已使用 DeepSeek 对 NCT02347774 完成一次真实在线解析，得到 25 条待审核候选规则，并成功同步至飞书。该次运行用于验证端到端链路，不等同于正式 F1 评测。目标 F1 ≥ 0.85，仍不能在完成人工逐项比对前写成已达成结果。

### 规则引擎

- 50 个边界病例总体状态准确率；
- 所有支持运算符的边界与等号语义；
- `不符合 > 信息不足 > 人工复核 > 模拟符合` 的优先级；
- 每项证据的标准原文、患者值与阈值完整性。

当前离线测试对 50 个病例的总体状态判断为 50/50，通过率 100%。该数字只验证代码行为，不代表真实临床准确性。

## 4. 失效场景

- 扫描 PDF：明确提示暂不支持 OCR；
- 未找到章节：展示全文并要求人工确认；
- 空响应或无效 JSON：最多重试两次，保留原文；
- 无 Key、断网或达到限额：GOLDEN-4 缓存演示继续运行；
- 缺失患者字段：输出“信息不足”，不静默判为不符合；
- 主观标准：输出“人工复核”。


运行结果应显示 500 名合成患者、50 个边界病例，并通过全部测试。
